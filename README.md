# Oude-hoeve.nl

Website voor bed & breakfast D'Oude Hoeve, Hoefstraat 3, 4891 ZE Rijsbergen.

## Inhoud
- `index.html` — hoofdpagina (zelfstandig bestand, alle foto's en fonts inbegrepen)
- `fotos.html` — fototour

## Publiceren via GitHub Pages
1. Maak een repository (bijv. `oude-hoeve`) en upload beide bestanden.
2. Ga naar Settings → Pages → kies branch `main`, map `/ (root)` en sla op.
3. De site staat daarna op `https://<gebruikersnaam>.github.io/<repo>/`.
4. Eigen domein (oude-hoeve.nl): voeg bij Settings → Pages je domein toe en zet bij je registrar een CNAME/A-record naar GitHub Pages.
